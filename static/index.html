Value tips

  • Check a place's own menu link before a delivery app — delivery markups can add dollars to the same item.
  • “Deals” links search the place's real coupons and offers; if nothing turns up, that place may simply not run deals.
  • Lunch specials and value menus usually live on the restaurant's own site, not on map listings.
  • Distances here are straight-line from your crossroads — a 2-minute walk across the same strip mall beats a drive across a busy arterial.
